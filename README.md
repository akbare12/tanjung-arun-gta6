TANJUNG ARUN — BADAI ARUNIKA: an all-original open-world crime game in a coastal Indonesian city, with a 7-day hurricane countdown that changes gameplay — police chases with a helicopter, 8 story missions, a disguise system, garage upgrades, and 3 radio stations. Playable offline in a desktop browser.

## Run it

```sh
python3 -m http.server 8000 --directory game
```

Then open http://localhost:8000 in a desktop browser.
