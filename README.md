Game open-world crime 3D low-poly (Three.js r160, offline, tanpa network) di kota
pesisir Indonesia. Tujuh hari menuju badai: kabur dari blokade polisi di jalan
pantai, serbu gudang pelabuhan saat hujan malam, dan kelola panas, uang, serta
kru sebelum Badai Arunika mendarat.

Main di sini: [Tanjung Arun — Badai Arunika di make.fun](https://make.fun/c/gta6-01?ref=v7znzvhb)

## Cara main

Buka `game/index.html` di desktop Chrome (offline, tanpa server). Atau:

```sh
node --run serve  # bila serve.ts tersedia; jika tidak, buka file langsung
```

- **WASD** jalan / nyetir, **SHIFT** lari, **SPASI** rem tangan
- **E** interaksi, **M** peta, **C** ganti kamera, **R** ganti radio
- **Mouse drag** orbit kamera

## Isi game

- **Kota hidup**: gedung berfasad jendela menyala + balkon 3D + papan nama toko,
  palem & pohon rindang, pejalan kaki 50+ dengan pose bervariasi, lalu lintas.
- **Banjir rob**: air pasang masuk jalan pantai — karung pasir, rambu peringatan,
  mobil setengah tenggelam.
- **Kejar-kejaran**: polisi mengejar dari belakang (Unit Macan, Elang, Badak),
  helikopter dengan sorot melebar ke tanah + kolam cahaya, perahu & dermaga
  di laut.
- **Sistem bernama**: dispatch polisi (unit + jarak + aksi), dialog fixer Bang Jaka,
  kru (Sari, Pakde Rojak, Lintang), radio Arunika 98.5 (DJ Nadia Senja) &
  Ombak 101.2 (DJ Budi Gelombang), 3 slot simpan.
- **Misi 8 bab** (M1–M8), paket koleksi 24, peta kota lengkap dengan distrik,
  hitung mundur badai 7 hari (CAT 2 → CAT 4), wanted level, skor aksi melayang.
